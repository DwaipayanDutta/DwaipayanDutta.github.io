# Personal Portfolio — Dwaipayan Dutta

A minimal, editorial-style personal portfolio website built with **HTML5, CSS3, and modern typography**.

🌐 **Live Website:** [dwaipayandutta.github.io](https://dwaipayandutta.github.io)

---

## 📌 Overview

This repository contains the source code for my personal portfolio website, showcasing my work and experience as a **Data Science Leader & AI Solution Architect**.

The site is intentionally lightweight, responsive, and dependency-free, focusing on typography, structure, and content rather than heavy frameworks.

### Highlights & Design Choices

- **Editorial & Clean Typography**  
  Uses Google Fonts — `Inter` and `Courier Prime` — combined with carefully structured layout grids for readability and visual hierarchy.

- **Responsive Layout**  
  Designed to work across desktop, tablet, and mobile devices using native **CSS Grid** and **Flexbox**.

- **Zero Dependencies**  
  Built with plain HTML and CSS without heavy frameworks or JavaScript libraries, keeping the site lightweight and fast.

- **Data-First Visuals**  
  Uses custom CSS metric cards, timeline layouts, and CSS-based visual accents to present information clearly.

- **Minimal Architecture**  
  The portfolio is intentionally maintained as a simple static website, making it easy to understand, modify, and deploy.

## 🛠️ Local Development

### 1. Clone the Repository

```bash
git clone https://github.com/DwaipayanDutta/DwaipayanDutta.github.io.git
cd DwaipayanDutta.github.io
```

### 2. Open the Website

The website is completely static, so no build process or package installation is required.

You can open `index.html` directly in your browser.

**macOS:**

```bash
open index.html
```

**Linux:**

```bash
xdg-open index.html
```

**Windows:**

```powershell
start index.html
```

### 3. Using VS Code

Alternatively, open the project in **Visual Studio Code** and use the **Live Server** extension for local development and automatic browser refresh.
